# Полная настройка голосового ассистента на Raspberry Pi OS

Пошаговая инструкция по развёртыванию голосового ассистента на «чистой»
Raspberry Pi (рекомендуется Pi 4 / Pi 5, 4 ГБ RAM или больше).

Ассистент состоит из четырёх частей:
- **Vosk** — распознавание речи (offline)
- **spaCy + кастомный классификатор интентов** — определение команды
- **Silero TTS** — синтез русской речи
- **Навыки (skills)** — погода, радио, сказки, базовые команды

---

Обновите систему и установите системные зависимости. Они нужны для звука
(ALSA/PulseAudio), микрофона, потокового аудио (VLC/ffmpeg) и сборки

    python3-venv python3-pip python3-dev \
    libportaudio2 libatlas-base-dev libsndfile1 libatomic1 \
    vlc mpg123 ffmpeg \

| Пакет | Зачем нужен |
|---|---|
| `python3-venv`, `python3-pip` | Виртуальное окружение и установка Python-пакетов |
| `libportaudio2` | Для `sounddevice` (запись/воспроизведение через PortAudio) |
| `libatlas-base-dev` | Численные операции для NumPy |
| `libsndfile1` | Чтение/запись аудиофайлов |
| `vlc`, `ffmpeg`, `mpg123` | Резервные плееры для стриминга |
| `alsa-utils`, `pulseaudio` | Управление звуком и микрофоном |

## 5. Настройка звука

### Проверьте устройства

```bash
# Список входов (микрофоны)
arecord -l

# Список выходов (динамики)
aplay -l
```

### ⚠️ Важно для I²S-плат (voiceHAT, SPH0645 + MAX98357A)

I²S-устройства поддерживают на железном уровне только **48000 Гц**.
Vosk требует **16000 Гц**, Silero TTS выдаёт **24000 Гц**, MP3-радио
обычно идёт на **44100 Гц**. Без ALSA-конвертера PortAudio падает с
ошибкой `Invalid sample rate [PaErrorCode -9997]`.

Решение — настроить ALSA так, чтобы устройство по умолчанию автоматически
выполняло **ресэмплинг** через `plughw`. Создайте файл `~/.asoundrc`:

```bash
cat > ~/.asoundrc << 'EOF'
# Простейшая конфигурация для I²S-карты.
# plughw = автоматический ресэмплинг без слоя dmix
# (который на Pi даёт underrun из-за маленького буфера).
pcm.!default {
    type asym
    playback.pcm "plughw:0,0"
    capture.pcm  "plughw:0,0"
}

ctl.!default {
    type hw
    card 0
}
EOF
```

В файле `0` — номер карты voiceHAT (видно в выводе `aplay -l`).
Если ваша I²S-карта имеет другой индекс — замените `0,0` на правильные.

> **Почему так просто?** Регулировка громкости (команды «громче»,
> «тише», «громкость 50», auto-ducking) делается **программно в коде
> ассистента** — PCM-сэмплы умножаются на коэффициент громкости перед
> отправкой в `aplay`/`sounddevice`. Это нужно потому, что I²S-DAC вроде
> MAX98357A не имеет аппаратной регулировки громкости: чип играет ровно
> те цифры, что ему отдали. ALSA-микшер `Master` на таких платах
> бутафорский. Программная регулировка работает с любой версией ALSA
> и не требует дополнительных плагинов.

> **Почему без dmix?** dmix позволяет нескольким приложениям одновременно
> писать звук в одно устройство, но на Pi с медленным CPU его внутренний
> буфер маленький и не успевает заполняться → стена `underrun occurred`
> в логах. Ассистент единственный издатель аудио, dmix не нужен.

Если вы уже создавали `~/.asoundrc` по предыдущей версии этой
инструкции — **обязательно перезапишите** его командой выше.

**Проверка работы:**

```bash
# Должно воспроизвести тестовый звук на 16, 24 и 48 кГц без ошибок:
speaker-test -D default -r 16000 -c 1 -t sine -f 440 -l 1
speaker-test -D default -r 24000 -c 1 -t sine -f 440 -l 1
speaker-test -D default -r 48000 -c 1 -t sine -f 440 -l 1

# И запись на 16 кГц:
arecord -D default -r 16000 -f S16_LE -c 1 -d 3 test.wav && aplay test.wav
```

Если все три воспроизведения и запись работают — ALSA настроен правильно.

### Регулировка громкости

```bash
alsamixer
```

В `alsamixer` нажмите **F6** для выбора звуковой карты, стрелками
поднимите уровни **Master**, **Speaker** и **Capture** (микрофон).
Сохраните: `sudo alsactl store`.

### Расслышать команду поверх играющего радио (Auto-ducking)

В коде уже реализован механизм **auto-ducking**: когда Vosk в потоковом
(partial) распознавании увидит имя ассистента, громкость **автоматически
опускается до 25%**, и пользовательскую команду становится легче расслышать.
По окончании обработки громкость возвращается на прежний уровень.

Никаких дополнительных действий для этого не требуется — работает «из коробки».

### Опционально: акустический эхо-канселлер (AEC)

Для максимально чистого распознавания поверх громкого воспроизведения
можно подключить **WebRTC AEC** через PulseAudio:

```bash
# Включить эхо-канселлер
pactl load-module module-echo-cancel \
    aec_method=webrtc \
    source_name=echocancel_source \
    sink_name=echocancel_sink

# Установить новые виртуальные устройства источниками по умолчанию
pactl set-default-source echocancel_source
pactl set-default-sink   echocancel_sink
```

Чтобы AEC включался автоматически при загрузке, добавьте в
`/etc/pulse/default.pa` (для системной PulseAudio) или
`~/.config/pulse/default.pa` (для пользовательской) строку:

```
load-module module-echo-cancel aec_method=webrtc
```

AEC требует немного CPU (около 5–8% на одном ядре Pi 4) и работает
поверх любого микрофона — в том числе I²S воркеры виноваты, к нему
применяется тот же приём.

### Альтернатива: выбор устройства из кода

Если хочется временно выбрать конкретное устройство без правки
`~/.asoundrc`, можно задать переменную окружения перед запуском:

```bash
# Формат: "input_idx,output_idx" или просто имя устройства
export AUDIO_DEVICE="0,0"
python main.py
```

Этот вариант полезен для отладки. Постоянное решение для Pi — всё-таки
`~/.asoundrc`.

### Голосовые/текстовые интенты (через NLP-модель)

| Интент | Примеры |
|---|---|
| **Сказка** | «включи сказку колобок», «расскажи про репку», «поставь аудиокнигу про животных» |
| **Погода** | «какая погода в Воронеже», «погода завтра в Москве», «прогноз на послезавтра» |
| **Радио** | «включи радио маяк», «поставь европу плюс», «давай радио» |
| **Таймер** | «таймер на 5 минут», «засеки 30 секунд», «разбуди через час», «отмени таймер» |
| **Гороскоп** | «гороскоп для овна», «мой гороскоп близнецы», «что говорят звезды», «гороскоп козерога» |
| **Напоминание** | «напомни через 5 минут полить цветы», «через час напомни выпить таблетку», «разбуди меня через 30 минут», «напомни в 18:30 позвонить маме», «отмени напоминания» |
| **Прочее** | Любое другое — ассистент скажет, что не понял |

### Системные команды (точное совпадение, минуют NLP)

| Команда | Действие |
|---|---|
| `стоп`, `стой`, `остановись`, `замолчи`, `хватит` | Остановить текущее воспроизведение |
| `громче`, `прибавь`, `погромче` | Увеличить громкость на один шаг |
| `тише`, `убавь`, `потише` | Уменьшить громкость на один шаг |
| `громкость 50` / `громкость пятьдесят` | Установить точный уровень громкости 0–100 |
| `выключи радио`, `выключи сказку` | Остановить воспроизведение |
| `перезагрузи`, `ребут` | Перезагрузить Pi |
| `выключи`, `отключи питание` | Выключить Pi |

Громкость во время воспроизведения **не прерывает аудио** — управляется
через `amixer` параллельно.

## 10. Решение проблем

### Микрофон не слышит
- `alsamixer` → поднимите уровень **Capture** (нажав «Space» включите запись)
- Проверьте `arecord -l` — там должно быть устройство
- Иногда USB-микрофон требует перезагрузки: `sudo reboot`

### Нет звука
- `alsamixer` → поднимите **Master** и **Speaker**, снимите Mute (клавиша «M»)
- Проверьте, что выход правильный: `sudo raspi-config` → Advanced → Audio

### `PaErrorCode -9997` / `Invalid sample rate`
Аппаратура (особенно I²S-HAT'ы) не поддерживает запрошенную частоту
дискретизации. Лечится созданием `~/.asoundrc` с обёрткой `plug` —
подробности см. в **разделе 5** «Настройка звука». После создания файла
перезапустите ассистент.

### `Expression 'paAlsaStream...' failed`
То же самое, что и `PaErrorCode -9997`. Сценарий тот же.

### `ModuleNotFoundError`
- Убедитесь, что активировано виртуальное окружение: `source .venv/bin/activate`
- Переустановите зависимости: `pip install -r requirements.txt`

### Радио не запускается / ошибки декодирования
- Проверьте интернет: `ping radio-browser.info`
- Установите системные кодеки: `sudo apt install -y libavcodec-extra`

### Модель интентов не найдена
- Запустите обучение: `cd core/nlp && python train_intent_classifier.py`
- Папка `core/nlp/models/intent_model/` должна появиться

### Логи systemd-сервиса
```bash
journalctl -u voice-assistant -n 100 --no-pager
```

## 11. Дополнительно

### Ускорение TTS через кэш

При каждом первом произнесении новой фразы Silero TTS работает на Pi
довольно медленно (3–7 секунд для одного предложения). Поэтому
синтезированные WAV-файлы сохраняются в `core/assets/tts_cache/` —
ключ кэша считается как MD5-хеш от `(текст, голос, sample_rate)`.

При повторе той же реплики Silero не вызывается вообще, готовый WAV
сразу идёт в `aplay`. Поскольку большинство ответов ассистента
повторяются («Готово», «Не поняла», «Поставила таймер на пять минут»,
«Включаю Радио Маяк»), уже после нескольких минут использования
большинство фраз отвечают **мгновенно**.

Если кэш мешает (например, после смены голоса хочется очистить),
просто удалите папку:

```bash
rm -rf ~/graduation-project/core/assets/tts_cache
```

При следующем запуске она будет создана заново и постепенно заполнится.
